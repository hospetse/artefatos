# Artefatos do HOSPETSE

Documentos, diagramas e especificações do Hospetse, separados por etapa do projeto. Cada pasta tem um `README.md` que explica o que ela contém e por onde começar.

O código fica nos repositórios [hospetse-mobile](https://github.com/hospetse/hospetse-mobile), [hospetse-auth-service](https://github.com/hospetse/hospetse-auth-service) e [hospetse-backend](https://github.com/hospetse/hospetse-backend).

## Etapas

| Etapa | Pasta | Escopo |
|---|---|---|
| 1º semestre (2026.1) | [1o-semestre](1o-semestre) | MVP de hospedagem: buscar Host e solicitar reserva. Registro histórico |
| 2º semestre (2026.2) | [2o-semestre](2o-semestre) | Produto completo: Tutor, Host, Pet Sitter, Pet Walker e módulo administrativo. **Documentação atual** |

## Como ler os arquivos

| Formato | Como abrir |
|---|---|
| `.md` | O GitHub mostra o texto formatado, com os diagramas embutidos |
| `.svg` | Diagrama. Abre no GitHub ou no navegador e pode ser ampliado sem perder qualidade |
| `.puml` | Código-fonte do diagrama em [PlantUML](https://plantuml.com). Serve para editar e gerar o `.svg` de novo |
| `.pdf`, `.xlsx` | Documentos e planilhas. O GitHub oferece o botão de download |

## Wiki do Azure DevOps

Os documentos do 2º semestre também estão na Wiki do projeto no Azure DevOps, indicada como **Wiki #n** nos READMEs. A Wiki é a fonte de trabalho do time e é privada: só abre para quem tem acesso ao projeto `Hospetse` na organização `escola-ti`. As cópias aqui servem para leitura pública.

Documentos extras, em PDF, Word e Excel, estão na [pasta do projeto no Google Drive](https://drive.google.com/drive/folders/1nrYGjsp7fLBej4jro9sgQZ-MuqHesd78?usp=sharing).
