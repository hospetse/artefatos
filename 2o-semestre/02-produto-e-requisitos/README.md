## Como os artefatos se ligam

- Cada caso de uso tem ID `HPETnn` (por exemplo, `HPET03 — Buscar Serviços`), com atores, pré-condições, fluxo principal e fluxos alternativos.
- As user stories quebram os casos de uso em entregas e trazem os critérios de aceite.
- A matriz de rastreabilidade liga cada caso de uso ao Epic, à Feature e aos PBIs do backlog no Azure Boards.
- Os diagramas de casos de uso estão em [04-modelagem/casos-de-uso](../04-modelagem/casos-de-uso).
